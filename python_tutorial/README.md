# Python 学习教程：从基础语法到船舶 RL 仿真

本教程是一套面向**只有基础 Python 知识**的读者的入门教程，以本仓库的研究项目——双全回转推进船舶 3DOF 灰箱建模与强化学习控制——为贯穿始终的背景案例。学完本教程，你将能够用 Python 完成该项目涉及的主要编程工作：数值仿真、数据处理、参数辨识、可视化，以及搭建强化学习训练环境。

## 面向读者与前置条件

- **读者画像**：会 Python 基础语法（变量、数值/字符串、列表/字典、if/for/while、def 函数、简单文件读写），但从未用过 NumPy、pandas、PyTorch 等科学计算库，也不要求船舶或控制专业背景——所有领域术语首次出现时都有通俗解释。
- **运行环境**：Python 3.10 及以上；第三方库为 numpy、matplotlib、pandas、scipy，第 9 章另需 PyTorch（CPU 版即可）。具体安装步骤见第 1 章。

## 全书统一约定

- 符号：位置姿态 η=(x, y, ψ)（代码变量 `x, y, psi`），速度 ν=(u, v, r)（纵荡/横荡/艏摇角速度），双推进器转速 `n1, n2`、方位角 `alpha1, alpha2`，合力/力矩 `X, Y, N`，时间步长 `dt`。
- 教程中的物理模型均为**教学简化模型**（例如对角质量矩阵、线性阻尼），不是研究用的 MMG 模型；简化处在各章均有注明。
- 各章引用 `research/` 研究文档时均标注了对应小节，学有余力可对照原文深入。

## 与研究文档的关系

本教程是研究文档（`research/` 目录，第 0~6 章）的"编程前置课"：研究文档回答"做什么、为什么"，本教程回答"用 Python 怎么动手"。学完本教程后，可按根目录 [README](../README.md) 的文档导航进入研究文档：做选型读第 0、1、5 章，做辨识读第 2、4 章，组织试航读第 3 章，接入 RL 读第 4、6 章。
