## 11.2 model.py：船舶模型

回顾符号：位置姿态 `η=(x,y,psi)`（psi 是艏向角，即船头指向的角度），速度 `ν=(u,v,r)`（u 纵荡速度、v 横荡速度、r 艏摇角速度，即沿船身前后/左右/转头的运动）。双推进器转速 `n1,n2`、方位角 `alpha1,alpha2`，推力产生合力/力矩 `X,Y,N`。

```python
# 文件：ship_sim/model.py
"""教学简化的 3DOF 船舶模型（真实项目用 MMG 灰箱模型，见 research/ 第 2 章）"""
import numpy as np

# “真实船舶”的参数：仿真数据由它生成，辨识阶段假装未知
TRUE_PARAMS = dict(Xu=20.0, Xuu=30.0, Yv=50.0, Yvv=80.0, Nr=15.0, Nrr=25.0)
M = np.array([25.0, 40.0, 12.0])  # 纵荡/横荡/艏摇三个方向的惯量（含附加质量）
KT = 0.8                          # 推力系数：单台推力 T = KT * n * |n|
LX, LY = -1.0, 0.5                # 推进器安装位置：x=LX，y=+LY 与 y=-LY
N_MAX = 15.0                      # 转速限幅


def wrap_angle(a):
    """把角度折算到 (-pi, pi]，避免艏向角误差出现 359° 减 -1° 的跳变"""
    return (a + np.pi) % (2 * np.pi) - np.pi


def thrust_forces(n1, n2, alpha1, alpha2):
    """由双机转速与方位角计算船体坐标系下的合力 X、Y 与艏摇力矩 N"""
    t1 = KT * n1 * np.abs(n1)
    t2 = KT * n2 * np.abs(n2)
    fx1, fy1 = t1 * np.cos(alpha1), t1 * np.sin(alpha1)
    fx2, fy2 = t2 * np.cos(alpha2), t2 * np.sin(alpha2)
    X = fx1 + fx2
    Y = fy1 + fy2
    N = LX * (fy1 + fy2) - LY * fx1 + LY * fx2  # 力矩 = x*Fy - y*Fx
    return X, Y, N


def dynamics(nu, forces, p):
    """动力学方程：返回加速度 (du, dv, dr)（教学简化：阻尼解耦）"""
    u, v, r = nu
    X, Y, N = forces
    du = (X - p["Xu"] * u - p["Xuu"] * u * abs(u)) / M[0]
    dv = (Y - p["Yv"] * v - p["Yvv"] * v * abs(v)) / M[1]
    dr = (N - p["Nr"] * r - p["Nrr"] * r * abs(r)) / M[2]
    return np.array([du, dv, dr])


def step(eta, nu, action, p, dt):
    """欧拉积分推进一步，action = (n1, n2, alpha1, alpha2)"""
    forces = thrust_forces(*action)
    nu = nu + dynamics(nu, forces, p) * dt
    psi = eta[2]
    c, s = np.cos(psi), np.sin(psi)
    rot = np.array([[c, -s], [s, c]])  # 船体系 → 大地系的旋转矩阵
    eta = eta.copy()
    eta[:2] = eta[:2] + rot @ nu[:2] * dt
    eta[2] = eta[2] + nu[2] * dt
    return eta, nu
```

要点：`step()` 就是第 4 章的欧拉积分加第 3 章的旋转矩阵。阻尼写成"线性项 + 二次项"（如 `Xu*u + Xuu*u*|u|`），这是教学简化——真实 MMG 模型的阻尼项更复杂且各自由度耦合，但辨识套路相同。`thrust_forces` 全部用 `np.*` 函数，因此标量和数组都能算，后面辨识时直接对整列数据向量化。阻尼参数（`Xu` 等）扮演"待辨识未知量"：真实项目中它们来自试航数据，见 research/ 第 2 章的可辨识性分析。

## 11.3 identify.py：数据生成、划分与辨识

```python
# 文件：ship_sim/identify.py
"""数据生成、数据划分与最小二乘参数辨识"""
import numpy as np
import pandas as pd

from .model import TRUE_PARAMS, M, dynamics, step, thrust_forces

DT = 0.1  # 时间步长，全书统一符号 dt


def simulate_dataset(n_steps=6000, seed=42):
    """用“真实参数”仿真一段试航数据，返回 DataFrame。

    教学简化：加速度 du/dv/dr 直接记录；真实试航中加速度要由
    速度量测差分并滤波得到（见 research/ 第 3 章的数据需求）。
    """
    rng = np.random.default_rng(seed)
    eta, nu = np.zeros(3), np.zeros(3)
    action = np.array([0.0, 0.0, 0.0, 0.0])
    rows = []
    for k in range(n_steps):
        if k % 50 == 0:  # 每 5 秒随机更换一次推进指令，保证充分激励
            action = np.array([
                rng.uniform(-12, 15), rng.uniform(-12, 15),
                rng.uniform(-0.5, 0.5), rng.uniform(-0.5, 0.5)])
        du, dv, dr = dynamics(nu, thrust_forces(*action), TRUE_PARAMS)
        # 量测噪声：速度 0.02 m/s、艏摇角速度 0.01 rad/s、加速度 0.05
        meas = [*nu[:2] + rng.normal(0, 0.02, 2),
                nu[2] + rng.normal(0, 0.01),
                du + rng.normal(0, 0.05), dv + rng.normal(0, 0.05),
                dr + rng.normal(0, 0.05)]
        rows.append([k * DT, *eta, *meas, *action])
        eta, nu = step(eta, nu, action, TRUE_PARAMS, DT)
    cols = ["t", "x", "y", "psi", "u", "v", "r", "du", "dv", "dr",
            "n1", "n2", "alpha1", "alpha2"]
    return pd.DataFrame(rows, columns=cols)


def split_dataset(df):
    """按时间顺序连续切成 60/20/20 的 train/val/test 三段。

    时间序列数据不能随机打乱：打乱了同一段机动会同时漏进训练集
    和测试集。教学简化：真实项目应按航次（整段记录）划分并提前
    冻结（见 research/ 第 4 章）。
    """
    n = len(df)
    train = df.iloc[: int(0.6 * n)]
    val = df.iloc[int(0.6 * n): int(0.8 * n)]
    test = df.iloc[int(0.8 * n):]
    return train, val, test


def identify_damping(train):
    """逐通道用 lstsq 辨识线性阻尼与二次阻尼。

    以纵荡为例：X_thrust - M*du = Xu*u + Xuu*u*|u|，
    对 [u, u*|u|] 做最小二乘即可解出 Xu、Xuu。
    """
    n1, n2 = train["n1"].to_numpy(), train["n2"].to_numpy()
    a1, a2 = train["alpha1"].to_numpy(), train["alpha2"].to_numpy()
    X, Y, N = thrust_forces(n1, n2, a1, a2)
    jobs = [("u", "du", X, M[0], ["Xu", "Xuu"]),
            ("v", "dv", Y, M[1], ["Yv", "Yvv"]),
            ("r", "dr", N, M[2], ["Nr", "Nrr"])]
    params = {}
    for vel_col, acc_col, force, mass, names in jobs:
        v = train[vel_col].to_numpy()
        b = force - mass * train[acc_col].to_numpy()
        A = np.column_stack([v, v * np.abs(v)])
        coef, *_ = np.linalg.lstsq(A, b, rcond=None)
        params[names[0]], params[names[1]] = coef
    return params


def free_roll_rmse(params, df):
    """自由滚动评估：只用初始状态，之后全靠模型自己积分，比较轨迹误差"""
    eta = df[["x", "y", "psi"]].iloc[0].to_numpy().astype(float)
    nu = df[["u", "v", "r"]].iloc[0].to_numpy().astype(float)
    errs = []
    for row in df.itertuples():
        eta, nu = step(eta, nu, [row.n1, row.n2, row.alpha1, row.alpha2],
                       params, DT)
        errs.append(eta - np.array([row.x, row.y, row.psi]))
    errs = np.array(errs)
    return np.sqrt(np.mean(errs ** 2, axis=0))  # x、y、psi 各自的 RMSE
```

两个新概念。**自由滚动**（free-roll）：不逐步喂真值，而是把模型上一步的预测当作下一步的起点，误差会逐步累积——它比"一步预测误差"更能暴露模型问题，这正是 README 里"自由滚动和闭环表现优先"的原因。**RMSE**（均方根误差）：误差平方求平均再开根号，单位与原量一致，越小越好。辨识部分就是第 7 章的 `np.linalg.lstsq`：把动力学方程移项，使未知参数变成线性回归的系数。

## 11.4 env.py 与 control.py：环境与控制器

Gym 风格环境是强化学习社区的通用接口约定：`reset()` 返回初始观测，`step(action)` 返回 `(观测, 奖励, 是否结束, 附加信息)`。有了它，PD 控制器和第 10 章的 RL 算法可以不加修改地换着用。

```python
# 文件：ship_sim/env.py
"""Gym 风格环境封装：把辨识出的模型包装成 reset()/step() 接口"""
import numpy as np

from .model import N_MAX, step, wrap_angle


class ShipHeadingEnv:
    """保向任务环境：动作是双机转速 (n1, n2)，方位角固定朝前。

    观测向量 obs = [x, y, psi, u, v, r, 艏向误差]，
    奖励 = -(艏向误差^2 + 0.1 * 艏摇角速度^2)。
    """

    def __init__(self, params, dt=0.1, max_steps=600, psi_target_deg=30.0):
        self.params = params          # 用辨识参数驱动环境，而不是真实参数
        self.dt = dt
        self.max_steps = max_steps
        self.psi_target = np.deg2rad(psi_target_deg)

    def reset(self):
        """初始化状态并返回第一条观测"""
        self.eta = np.zeros(3)
        self.nu = np.zeros(3)
        self.t = 0
        return self._obs()

    def _obs(self):
        err = wrap_angle(self.psi_target - self.eta[2])
        return np.array([*self.eta, *self.nu, err])

    def step(self, action):
        """执行一步动作，返回 (obs, reward, done, info)"""
        n1, n2 = np.clip(action, -N_MAX, N_MAX)  # 执行器限幅
        self.eta, self.nu = step(self.eta, self.nu, [n1, n2, 0.0, 0.0],
                                 self.params, self.dt)
        self.t += 1
        obs = self._obs()
        reward = -(obs[6] ** 2 + 0.1 * self.nu[2] ** 2)
        done = self.t >= self.max_steps
        return obs, reward, done, {}
```

注意 `__init__` 接收的是**辨识出的参数**——RL 策略将来就在这个"学出来的模型"里训练，模型误差会直接传导到策略表现，这就是第 4 步认真评估 RMSE 的意义。

控制器用 PD（比例-微分）控制：输出 = 比例项 × 误差 + 微分项 × 误差变化率，这里微分项直接用艏摇角速度 r 近似。保向（heading control）即把艏向角稳定在目标值。

```python
# 文件：ship_sim/control.py
"""PD 保向控制器与推力分配"""
import numpy as np

from .model import KT, LY, N_MAX


class PDHeadingController:
    """比例-微分（PD）控制器：根据艏向误差和艏摇角速度给出双机转速。

    分配原理（教学简化的小信号线性化）：方位角朝前时，
    N ≈ -4 * LY * KT * n_base * dn，因此 dn = -N_cmd / (4*LY*KT*n_base)。
    """

    def __init__(self, kp=20.0, kd=30.0, n_base=8.0):
        self.kp, self.kd, self.n_base = kp, kd, n_base

    def __call__(self, obs):
        err = obs[6]   # 艏向误差（已折算到 ±pi）
        r = obs[5]     # 艏摇角速度
        n_cmd = self.kp * err - self.kd * r      # 期望的艏摇力矩
        dn = -n_cmd / (4 * LY * KT * self.n_base)  # 折算成差动转速
        return np.clip([self.n_base + dn, self.n_base - dn], 0.0, N_MAX)
```

两台推进器一前一后共速（`n_base`）提供前进推力，一快一慢的差速（`dn`）产生转船力矩——这就是全回转船"无舵转向"的核心思想（教学简化的线性分配，真实分配要处理推力非线性与饱和）。

## 11.5 run_pipeline.py：总装流水线

```python
# 文件：ship_sim/run_pipeline.py
"""端到端流水线：仿真数据 → 辨识 → 评估 → 闭环控制 → 出图与实验记录"""
import pathlib

import matplotlib

matplotlib.use("Agg")  # 无界面环境下保存图片
import matplotlib.pyplot as plt
import numpy as np

from .control import PDHeadingController
from .env import ShipHeadingEnv
from .identify import (DT, free_roll_rmse, identify_damping,
                       simulate_dataset, split_dataset)
from .model import TRUE_PARAMS

OUT = pathlib.Path(__file__).resolve().parent  # 输出目录：ship_sim/
SEED_DATA = 42


def main():
    # 1. 仿真生成“试航数据”并保存 CSV（真实项目中这一步来自湖试记录）
    df = simulate_dataset(n_steps=6000, seed=SEED_DATA)
    csv_path = OUT / "trial_log.csv"
    df.to_csv(csv_path, index=False)

    # 2. pandas 划分 train/val/test
    train, val, test = split_dataset(df)

    # 3. lstsq 辨识阻尼参数，报告参数误差
    params = identify_damping(train)
    print("参数辨识结果（辨识值 / 真实值 / 相对误差）")
    for k, v in params.items():
        true = TRUE_PARAMS[k]
        print(f"  {k:4s} {v:8.2f} / {true:6.1f} / {abs(v - true) / true:6.2%}")

    # 4. 自由滚动 RMSE：val 用于检查过拟合，test 只做最终评估
    rmse_val = free_roll_rmse(params, val)
    rmse_test = free_roll_rmse(params, test)
    print(f"val  自由滚动 RMSE (x,y,psi): {np.round(rmse_val, 4)}")
    print(f"test 自由滚动 RMSE (x,y,psi): {np.round(rmse_test, 4)}")

    # 5. 用辨识出的模型封装环境，PD 控制器闭环保向
    env = ShipHeadingEnv(params, dt=DT)
    ctl = PDHeadingController()
    obs = env.reset()
    log = []
    done = False
    while not done:
        action = ctl(obs)
        obs, reward, done, _ = env.step(action)
        log.append([env.t * DT, *env.eta, *action])
    log = np.array(log)
    err_deg = np.rad2deg(log[-1, 3] - np.deg2rad(30.0))
    print(f"闭环结束艏向 {np.rad2deg(log[-1, 3]):.1f}°（目标 30°）")

    # 6. 画图：轨迹、艏向角、控制量三条曲线
    fig, axes = plt.subplots(3, 1, figsize=(7, 9))
    axes[0].plot(log[:, 1], log[:, 2])
    axes[0].set(xlabel="x / m", ylabel="y / m", title="轨迹")
    axes[1].plot(log[:, 0], np.rad2deg(log[:, 3]), label="实际艏向")
    axes[1].axhline(30.0, ls="--", color="gray", label="目标艏向")
    axes[1].set(xlabel="t / s", ylabel="psi / deg", title="艏向角")
    axes[1].legend()
    axes[2].plot(log[:, 0], log[:, 4], label="n1")
    axes[2].plot(log[:, 0], log[:, 5], label="n2")
    axes[2].set(xlabel="t / s", ylabel="转速", title="控制量")
    axes[2].legend()
    fig.tight_layout()
    fig.savefig(OUT / "figures" / "closed_loop.png", dpi=120)

    # 7. 输出一页实验记录（呼应 README“最小交付物”的教学版）
    lines = [
        "===== 实验记录 =====",
        f"配置: n_steps=6000, dt={DT}, 划分=60/20/20, PD(kp=20, kd=30, n_base=8)",
        f"随机种子: 数据={SEED_DATA}",
        f"数据文件: {csv_path.name} ({len(df)} 行)",
        f"test 自由滚动 RMSE: x={rmse_test[0]:.3f} m, "
        f"y={rmse_test[1]:.3f} m, psi={rmse_test[2]:.4f} rad",
        f"闭环最终艏向误差: {err_deg:.2f} deg",
    ]
    (OUT / "experiment_log.txt").write_text("\n".join(lines), encoding="utf-8")
    print("\n".join(lines))


if __name__ == "__main__":
    main()
```

## 常见错误

**错误 1：随机打乱时间序列再划分数据集。** `df.sample(frac=1)` 会让同一秒的前后数据分进训练集和测试集，测试集被"剧透"，RMSE 虚低。正确做法：按时间或按航次连续切分，见 `split_dataset`。

**错误 2：在包目录里直接运行脚本。** 在 `ship_sim/` 里执行 `python run_pipeline.py` 会报 `ImportError: attempted relative import with no known parent package`，因为相对导入只在"作为包的一部分"时有效。正确做法：退到上一级目录执行 `python -m ship_sim.run_pipeline`。

**错误 3：艏向误差直接相减。** `err = target - psi` 在 psi=359°、target=-1° 时得到 360° 的巨大误差，控制器会疯狂打满。正确做法：用 `wrap_angle` 把误差折算到 ±180° 内再进控制器。

**错误 4：图中文字变方块。** 部分 Linux 环境缺少中文字体，标题显示为 `□□`。可在 `import matplotlib.pyplot as plt` 后加 `plt.rcParams["font.sans-serif"] = ["Noto Sans CJK SC", "SimHei"]`，或把图中文字改成英文。

## 动手练习

1. 把 `PDHeadingController` 的 `kd` 从 30 改成 2 再运行，观察艏向角曲线的变化并解释原因。
2. 修改 `identify_damping`，只保留线性阻尼项（特征矩阵只放 `v` 一列，二次项系数设为 0），重新辨识并报告 test 自由滚动 RMSE，与完整模型对比。
3. 把目标艏向改为 -60°（修改 `run_pipeline.py` 第 5 步），确认闭环依然收敛，并解释为什么不需要改控制器代码。

## 参考答案

1. 艏向角会出现明显振荡、收敛变慢甚至超调多次。kd 是阻尼项，太小则抑制不住艏摇角速度 r，船会"转过头再回拉"。
2. 关键改动如下，其余不变：

```python
        A = v.reshape(-1, 1)          # 只保留线性项
        coef, *_ = np.linalg.lstsq(A, b, rcond=None)
        params[names[0]], params[names[1]] = coef[0], 0.0
```

此时 Xu 被高估到约 69.6（它被迫同时承担二次项的作用），test 自由滚动 RMSE 恶化到约 `[10.09, 6.49, 4.51]`——模型结构缺项时，参数再"最优"也补不回来，这就是可辨识性与模型结构要匹配的原因（research/ 第 2 章有深入讨论）。

3. 把第 5 步改为 `env = ShipHeadingEnv(params, dt=DT, psi_target_deg=-60.0)` 即可。控制器只读观测里的艏向误差 `obs[6]`，误差已经在 `_obs()` 里经过 `wrap_angle` 折算，所以 -60° 与 +30° 对控制器没有区别。
