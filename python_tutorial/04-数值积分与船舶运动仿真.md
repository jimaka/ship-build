## 4.1 本章学习目标

学完本章，你应该能够：

3. 按"初始状态 → 循环{取输入 → 算导数 → 积分 → 记录历史}"的标准结构组织任何仿真程序；

## 4.2 为什么学这一章

我们项目的核心是一个 3DOF 船舶运动模型：给定双推进器的转速和方位角，推算船的位置、艏向和速度随时间的变化。这类模型在数学上是一组**微分方程**，而计算机不会"解方程"，它只会做加减乘除——数值积分就是把微分方程翻译成加减乘除的桥梁。后面每一章都站在本章的肩膀上：第 7 章参数辨识要拿仿真轨迹去对比实测数据，第 8 章要把仿真器封装成 RL 环境，第 10 章里智能体每做一个动作，环境都要靠积分器推演一步后果。步长 `dt` 选错，模型写得再对，结果也是垃圾。本章只用 NumPy，有第 2、3 章的基础就够。

## 4.3 微分方程与"状态 → 导数 → 积分"的直觉

先统一本书的符号（与全书约定一致）：

| 符号 | 代码变量 | 含义 |
|---|---|---|
| η=(x, y, ψ) | `x, y, psi` | 地面坐标系下的位置与艏向角（ψ 是船头指向的角度，本章一律用弧度 rad） |
| ν=(u, v, r) | `u, v, r` | 船体系下的速度：u 纵荡速度（沿船头方向）、v 横荡速度（沿右舷方向）、r 艏摇角速度（转头快慢） |
| n1, n2 | `n1, n2` | 1 号/2 号推进器转速（单位 rps，转/秒） |
| alpha1, alpha2 | `alpha1, alpha2` | 1 号/2 号推进器方位角（全回转推进器可以水平旋转，方位角就是推力指向的角度，rad） |
| X, Y, N | `X, Y, N` | 双推进器合起来的纵向力、横向力、艏摇力矩 |
| dt | `dt` | 时间步长（积分每一步走多远，单位 s） |

**什么是微分方程？** 普通方程告诉你"未知量等于多少"，微分方程告诉你"未知量的**变化率**等于多少"。比如水箱水位 `h` 满足"下降速度正比于当前水位"：`dh/dt = -h`。知道变化率，又知道起点，就能一点点推回水位本身——这个过程叫**积分**。

船舶仿真一模一样。**状态**是我们要跟踪的量（位置、艏向、速度），**导数**是状态的变化率（位置的变化率是速度，速度的变化率是加速度）。牛顿第二定律给出加速度：力 ÷ 质量。于是整个仿真就是三步循环：

```text
状态 →（运动方程）→ 导数 →（积分一小步 dt）→ 新状态 → 再来一遍
```

以最简单的指数衰减 `dx/dt = -x`（可以想象成"船滑行时速度越快、阻力越大、掉速越快"）为例，它恰好有解析解 `x(t) = e^(-t)`，方便我们检验数值方法准不准。先用手算体会一步**欧拉法**：从 `x=1` 出发，当前导数是 `-1`，若步长 `dt=0.5`，就假设这 0.5 秒内变化率不变，于是

```text
x_new ≈ x + 导数 × dt = 1 + (-1) × 0.5 = 0.5
```

这就是全部思想：**用当前的斜率，直线外推一小步**。真正的解析解是 `e^(-0.5) ≈ 0.6065`，可见一步就误差不小——下一节看看怎么量化这个误差。

## 4.4 欧拉法：最简单的数值积分

欧拉法就一行核心代码：`state = state + f(state, t, u) * dt`。本书所有导数函数统一签名 `def f(state, t, u)`：`state` 是当前状态，`t` 是当前时间，`u` 是输入向量（本例没有外部输入，传 `None` 占位，船舶例子里它就是 `[n1, n2, alpha1, alpha2]`）。

把上面的手算循环起来：

```python
import numpy as np

def f(state, t, u):
    # 指数衰减：dx/dt = -x（本例没有外部输入，u 占位不用）
    return -state

dt = 0.5
n_steps = int(4.0 / dt)
x = 1.0
t = 0.0
print(f"{'t':>5} {'数值解':>10} {'解析解':>10}")
for k in range(n_steps + 1):
    print(f"{t:5.1f} {x:10.4f} {np.exp(-t):10.4f}")
    x = x + f(x, t, None) * dt   # 欧拉法：新状态 = 旧状态 + 导数 * dt
    t = t + dt
```

运行结果：

```text
    t        数值解        解析解
  0.0     1.0000     1.0000
  0.5     0.5000     0.6065
  1.0     0.2500     0.3679
  1.5     0.1250     0.2231
  2.0     0.0625     0.1353
  ...
  4.0     0.0039     0.0183
```

`dt=0.5` 时误差肉眼可见。直觉告诉我们：步长越小，"斜率不变"的假设越接近事实。量化验证一下，比较不同 `dt` 下 `t=2` 时刻的误差：

```python
import numpy as np

def f(state, t, u):
    return -state

def euler(f, state0, t0, t1, dt):
    """用欧拉法从 t0 积分到 t1，返回终点状态"""
    n_steps = int(round((t1 - t0) / dt))
    state = state0
    t = t0
    for k in range(n_steps):
        state = state + f(state, t, None) * dt
        t = t + dt
    return state

exact = np.exp(-2.0)
for dt in [0.5, 0.1, 0.01, 0.001]:
    x2 = euler(f, 1.0, 0.0, 2.0, dt)
    print(f"dt={dt:<6} 数值解={x2:.6f}  解析解={exact:.6f}  误差={abs(x2 - exact):.2e}")
```

运行结果：

```text
dt=0.5    数值解=0.062500  解析解=0.135335  误差=7.28e-02
dt=0.1    数值解=0.121577  解析解=0.135335  误差=1.38e-02
dt=0.01   数值解=0.133980  解析解=0.135335  误差=1.36e-03
dt=0.001  数值解=0.135200  解析解=0.135335  误差=1.35e-04
```

规律很清楚：**步长缩小 10 倍，误差大约也缩小 10 倍**——欧拉法是"一阶方法"，误差和 `dt` 成正比。想提高 10 倍精度，就要算 10 倍步数，代价线性增长。有没有更聪明的办法？

## 4.5 RK4：用 4 次采样换高阶精度

欧拉法只用**起点**的斜率外推，斜率在一步内变了就会偏。RK4（四阶龙格-库塔法）的思路是：在一步之内**多探几个点**的斜率——起点探一次、中点探两次、终点探一次，然后按 1:2:2:1 加权平均，用这个"平均斜率"走这一步：

```python
import numpy as np

def f(state, t, u):
    return -state

def euler_step(f, state, t, u, dt):
    return state + f(state, t, u) * dt

def rk4_step(f, state, t, u, dt):
    k1 = f(state, t, u)                             # 起点的斜率
    k2 = f(state + 0.5 * dt * k1, t + 0.5 * dt, u)  # 用 k1 探到中点的斜率
    k3 = f(state + 0.5 * dt * k2, t + 0.5 * dt, u)  # 用 k2 再探一次中点
    k4 = f(state + dt * k3, t + dt, u)              # 用 k3 探到终点的斜率
    return state + dt * (k1 + 2 * k2 + 2 * k3 + k4) / 6

def simulate(stepper, f, state0, t0, t1, dt):
    n_steps = int(round((t1 - t0) / dt))
    state, t = state0, t0
    for k in range(n_steps):
        state = stepper(f, state, t, None, dt)
        t = t + dt
    return state

exact = np.exp(-2.0)
for dt in [0.5, 0.1, 0.01]:
    x_eu = simulate(euler_step, f, 1.0, 0.0, 2.0, dt)
    x_rk = simulate(rk4_step, f, 1.0, 0.0, 2.0, dt)
    print(f"dt={dt:<5} 欧拉误差={abs(x_eu - exact):.3e}   RK4误差={abs(x_rk - exact):.3e}")
```

运行结果：

```text
dt=0.5   欧拉误差=7.284e-02   RK4误差=2.145e-04
dt=0.1   欧拉误差=1.376e-02   RK4误差=2.452e-07
dt=0.01  欧拉误差=1.356e-03   RK4误差=2.274e-11
```

`dt=0.5` 时 RK4 已经比 `dt=0.001` 的欧拉还准；而且步长缩小 10 倍，RK4 误差大约缩小 **10⁴ 倍**（"四阶"的名字由此而来）。代价是每步要调 4 次导数函数（欧拉只调 1 次），但换来的是允许用大得多的步长，通常稳赚。工程上可以直接用 `scipy.integrate.solve_ivp`（内部就是这类方法），但 RL 环境要自己控制每一步的输入，所以**手写积分循环的本事先学会**，第 8 章会用上。

## 4.6 仿真主循环的标准结构

无论欧拉还是 RK4、水箱还是船舶，仿真程序都长一个样。把下面这套结构刻进肌肉记忆：

```python
import numpy as np

def f(state, t, u):
    return -state

def command(t):
    return None          # 本例没有外部输入

# 1) 初始条件与参数
dt = 0.1
T = 4.0
n_steps = int(round(T / dt))
state = 1.0

# 2) 准备历史数组：列含义为 [t, x]
history = np.zeros((n_steps + 1, 2))
history[0] = [0.0, state]

# 3) 主循环：取输入 → 算导数 → 积分 → 记录
for k in range(n_steps):
    t = k * dt
    u_in = command(t)
    state = state + f(state, t, u_in) * dt
    history[k + 1] = [t + dt, state]

print("history 形状:", history.shape)
print("前 3 行:")
print(history[:3])
print(f"最后一行: t={history[-1,0]:.1f}, x={history[-1,1]:.6f} (解析解 {np.exp(-4.0):.6f})")
```

运行结果：

```text
history 形状: (41, 2)
前 3 行:
[[0.   1.  ]
 [0.1  0.9 ]
 [0.2  0.81]]
最后一行: t=4.0, x=0.014781 (解析解 0.018316)
```

三个细节值得注意：① 历史数组**预先分配** `(n_steps+1)` 行，比在循环里 `append` 列表快得多（第 2 章的向量化思想）；② `history[0]` 存初始状态，所以是 `n_steps+1` 行而不是 `n_steps` 行；③ 循环里 `history[k+1]` 存第 `k` 步**之后**的状态，和 `t+dt` 对齐。本书约定：船舶仿真的历史数组统一为 **7 列 `[t, x, y, psi, u, v, r]`**。

## 4.7 实战：教学简化版 3DOF 船舶仿真器

现在把真家伙装进去。**再次强调：这是教学简化模型，不是研究用的 MMG 模型。** 研究文档里的推进器模型还包含侧向力 S 项、执行器动态与角度校准等（见 `research/02-可辨识性分析.md`），本章全部省略，只保留骨干结构。

模型由两部分组成。**运动学**（船体系速度 → 地面坐标变化率，就是第 3 章的旋转矩阵）：

```text
dx/dt   = u·cos(ψ) − v·sin(ψ)
dy/dt   = u·sin(ψ) + v·cos(ψ)
dψ/dt   = r
```

**动力学**（对角质量矩阵 + 线性阻尼，最简形式）：

```text
m11·du/dt = X − d11·u        m22·dv/dt = Y − d22·v        m33·dr/dt = N − d33·r
```

**推进力分解**（教学简化：每台推进器的推力 T 沿其方位角 α 方向，T 与转速平方成正比；1 号机在右舷 `y=+d`，2 号机在左舷 `y=−d`，都在重心后 `x_p` 处）：

```text
T_i = C_T·n_i·|n_i|
X_i = T_i·cos(α_i)      Y_i = T_i·sin(α_i)      N_i = x_p·Y_i − y_i·X_i
```

完整代码（约 60 行，可直接运行）：

```python
import numpy as np
import matplotlib.pyplot as plt

# ---------- 教学简化参数（数值是编的，不是实船数据） ----------
M = np.diag([50.0, 80.0, 10.0])   # 质量矩阵（含附加质量）：纵向/横向/艏摇
D = np.diag([20.0, 60.0, 25.0])   # 线性阻尼矩阵
C_T = 0.5                          # 推力系数：T = C_T * n * |n|，n 单位 rps
X_P = -0.5                         # 推进器在重心后 0.5 m
D_Y = 0.3                          # 1 号机在右舷 +0.3 m，2 号机在左舷 -0.3 m

def thruster_forces(u_in):
    """由双推进器指令 [n1, n2, alpha1, alpha2] 计算合力 [X, Y, N]
    教学简化：忽略推进器侧向力 S，推力沿方位角方向分解"""
    n1, n2, alpha1, alpha2 = u_in
    X, Y, N = 0.0, 0.0, 0.0
    for n, alpha, y_p in [(n1, alpha1, +D_Y), (n2, alpha2, -D_Y)]:
        T = C_T * n * abs(n)          # n 为负表示倒车，推力反向
        X_i = T * np.cos(alpha)
        Y_i = T * np.sin(alpha)
        N_i = X_P * Y_i - y_p * X_i   # 力对重心的力矩
        X += X_i
        Y += Y_i
        N += N_i
    return np.array([X, Y, N])

def f(state, t, u):
    """3DOF 模型的导数函数：state=[x,y,psi,u,v,r]，u=[n1,n2,alpha1,alpha2]"""
    x, y, psi, uu, v, r = state      # uu 是纵荡速度，避免和输入向量 u 重名
    nu = np.array([uu, v, r])
    tau = thruster_forces(u)
    dnu = np.linalg.solve(M, tau - D @ nu)   # M*dnu/dt = tau - D*nu
    dx = uu * np.cos(psi) - v * np.sin(psi)  # 船体系速度转到地面坐标（第 3 章）
    dy = uu * np.sin(psi) + v * np.cos(psi)
    dpsi = r
    return np.array([dx, dy, dpsi, dnu[0], dnu[1], dnu[2]])

def command(t):
    """输入阶跃：前 10 s 双机正前方推进直航，之后方位角同转 0.2 rad 转向"""
    if t < 10.0:
        return np.array([10.0, 10.0, 0.0, 0.0])
    else:
        return np.array([10.0, 10.0, 0.2, 0.2])

# ---------- 仿真主循环 ----------
dt = 0.05
T = 25.0
n_steps = int(round(T / dt))
history = np.zeros((n_steps + 1, 7))   # 列：t, x, y, psi, u, v, r
state = np.zeros(6)                    # 初始静止在原点，艏向朝 +x
history[0, 0] = 0.0
history[0, 1:] = state

for k in range(n_steps):
    t = k * dt
    u_in = command(t)
    state = state + f(state, t, u_in) * dt   # 欧拉积分
    history[k + 1, 0] = t + dt
    history[k + 1, 1:] = state

# ---------- 查看结果 ----------
print(f"10 s 时纵荡速度 u = {history[200, 4]:.2f} m/s (理论稳态 X/d11 = {2*C_T*10**2/20:.1f} m/s)")
print(f"最终位置: x = {history[-1, 1]:.1f} m, y = {history[-1, 2]:.1f} m, psi = {np.rad2deg(history[-1, 3]):.1f} deg")
print(f"最终速度: u = {history[-1, 4]:.2f} m/s, v = {history[-1, 5]:.2f} m/s, r = {history[-1, 6]:.3f} rad/s")

plt.plot(history[:, 1], history[:, 2])   # 轨迹图；第 5 章会系统讲画图
plt.xlabel("x [m]"); plt.ylabel("y [m]"); plt.axis("equal")
plt.show()
```

运行输出：

```text
10 s 时纵荡速度 u = 4.91 m/s (理论稳态 X/d11 = 5.0 m/s)
最终位置: x = 33.9 m, y = -2.2 m, psi = -332.4 deg
最终速度: u = 4.90 m/s, v = 0.33 m/s, r = -0.397 rad/s
```

画出的轨迹是：先沿 +x 直航约 38 m，随后向 −y 一侧画出一个直径约 25 m 的近乎完整的圆。几个检查点帮你确认没写错：① 直航段 `u` 收敛到理论稳态 `X/d11 = 2×0.5×10²/20 = 5.0 m/s` 附近（10 s 时 4.91，合理，因为还在趋近）；② 转向后 `r` 收敛到常值 −0.397 rad/s，船进入稳定回转；③ 方位角转正、船却向负 ψ 方向转，是因为推进器在重心后方（`x_p<0`），正的横向力对重心产生负力矩——真实船舶的符号关系同样必须实测标定，不能想当然。另外 ψ 会累积到 −332° 没有回绕到 ±180° 内，本章从简不处理，记住真实项目里角度要做包络处理。

最后记住一个术语：像本例这样，模型每一步都**吃自己上一步预测出的状态**继续积分、全程不用实测数据修正，叫**自由滚动**（free-run）预测——第 7 章做参数辨识验证时，就是拿自由滚动轨迹去和实测轨迹比。

## 4.8 常见错误

**错误 1：步长太大，积分直接发散。** 对衰减更快的系统 `dx/dt = -10x`，用 `dt=0.25` 跑 5 步：

```python
import numpy as np

def f(state, t, u):
    return -10.0 * state   # 衰减更快的系统

for dt in [0.25, 0.05]:
    x, t = 1.0, 0.0
    for k in range(5):
        x = x + f(x, t, None) * dt
        t = t + dt
    print(f"dt={dt}: 5 步后 x = {x:.4f}  (t=1.25 解析解 {np.exp(-12.5):.2e})")
```

```text
dt=0.25: 5 步后 x = -7.5938  (t=1.25 解析解 3.73e-06)
dt=0.05: 5 步后 x = 0.0312  (t=1.25 解析解 3.73e-06)
```

`dt=0.25` 时数值解正负振荡、越滚越大，而解析解几乎衰减到 0。这不是"误差大"，是**彻底错了**。正确做法：把 `dt` 砍小重跑，或换 RK4；经验法则是 `dt` 要远小于系统最快的时间常数（本章船舶例子里最快的是艏摇 `m33/d33=0.4 s`，所以取 `dt=0.05`）。

**错误 2：把角度制传给三角函数。** NumPy 的 `np.cos`、`np.sin` 只吃弧度：

```python
import numpy as np

alpha = 30.0                      # 想表达 30 度
print("错误: np.cos(30)  =", np.cos(alpha))            # 0.154，不是 0.866！
print("正确: np.cos(30°) =", np.cos(np.deg2rad(alpha))) # 0.866
```

本书约定**程序内部一律用弧度**，只有给人看的打印输出才用 `np.rad2deg` 转成角度。

**错误 3：循环里每步都从初始状态出发。**

```python
# 错误示范：state 每步都被同一个值覆盖，历史数组里状态列全是同一个数
state0 = 1.0
for k in range(n_steps):
    t = k * dt
    state = state0 + f(state0, t, None) * dt   # 永远在用 state0，上一步的结果丢了！

# 正确写法：在 state 上累加，下一步用更新后的 state
state = state0
for k in range(n_steps):
    t = k * dt
    state = state + f(state, t, None) * dt
```

**错误 4：变量 `u` 一名两用。** 全书约定里 `u` 既是输入向量（`f(state, t, u)` 的第三个参数）又是纵荡速度，在函数内部解包时极易撞车：

```python
# 错误示范：解包把参数 u 覆盖了
def f(state, t, u):
    x, y, psi, u, v, r = state   # 参数 u（输入向量）被覆盖成纵荡速度（一个数）
    tau = thruster_forces(u)     # TypeError: cannot unpack non-iterable float object
```

正确做法：函数内把纵荡速度解包成 `uu`（本章船舶代码的写法），或者把输入参数改名 `u_in`，二者选一并全程序统一。

## 4.9 动手练习

1. **牛顿冷却**：物体温度 `x` 满足 `dx/dt = -0.3·(x − 20)`（20 是环境温度），初温 `x(0)=90`。用欧拉法、`dt=1.0` 积分到 `t=10`，与解析解 `x(t)=20+70·e^(−0.3t)` 对比误差；再把 `dt` 改成 0.1 看误差怎么变。
2. **差速转向**：复制 4.7 的仿真器，把 `command` 改成 `t≥10 s` 后 `n1=12, n2=8`（方位角保持 0），跑完看最终 ψ 的正负，并用合力公式解释船为什么转向、转向哪边。
3. **换积分器**：把 4.7 主循环里的欧拉改成 4.5 的 `rk4_step`，在 `dt=0.5` 这种"对欧拉来说偏大"的步长下分别跑两种方法，比较最终位置的差别。

## 4.10 参考答案

**练习 1**：核心代码与输出如下。`dt=1.0` 误差 1.51 °C，`dt=0.1` 误差 0.16 °C——大约也是"步长 ÷10，误差 ÷10"，符合欧拉法的一阶精度。

```python
import numpy as np

def f(state, t, u):
    return -0.3 * (state - 20.0)

dt = 1.0
x, t = 90.0, 0.0
for k in range(int(10.0 / dt)):
    x = x + f(x, t, None) * dt
    t = t + dt
exact = 20.0 + 70.0 * np.exp(-0.3 * 10.0)
print(f"t=10: 欧拉解 = {x:.3f}, 解析解 = {exact:.3f}, 误差 = {abs(x-exact):.3f}")
# 输出：t=10: 欧拉解 = 21.977, 解析解 = 23.485, 误差 = 1.508
# dt=0.1 时输出：23.329，误差 0.156
```

**练习 2**：最终 `psi ≈ -401.5°`，`r ≈ -0.48 rad/s`，船向负 ψ（本例坐标约定下的顺时针）一侧持续转向。原因：方位角都是 0 时 `Y=0`，但两台推力不等，`X_1 = 0.5×12² = 72 N`、`X_2 = 0.5×8² = 32 N`，合力矩 `N = d·(X_2 − X_1) = 0.3×(32−72) = −12 N·m < 0`。右舷（1 号机）推力更大，把船尾向右推，船头自然摆向另一边——这就是全回转船"差速转向"的原理。

**练习 3**：把主循环里 `state = state + f(state, t, u_in) * dt` 换成 `state = rk4_step(f, state, t, u_in, dt)` 即可（注意 `f` 不显式依赖 `t`，但签名保留 `t` 才能与 RK4 的中点求值兼容）。`dt=0.5` 下的结果：

```text
欧拉: 最终 x=34.16, y=-2.62, psi=-332.4 deg
RK4: 最终 x=33.92, y=-2.19, psi=-332.4 deg
```

RK4 的结果几乎和 `dt=0.05` 的精细结果（x=33.9, y=−2.2）重合，而欧拉已经漂了几十分米——同样的计算预算下，高阶方法允许更大的步长。
