# 第 7 章 最小二乘与参数辨识

本教程以双全回转推进船舶 3DOF 建模项目为背景。

## 本章学习目标

1. 理解把参数辨识问题写成 `y = Φθ` 回归形式的方法，能说清每一项的含义。
2. 会用 `np.linalg.lstsq` 求解最小二乘问题，并读懂它返回的秩与奇异值。
3. 独立完成"仿真生成数据 → 构造回归矩阵 → 辨识线性阻尼系数 → 与真值对比"的完整流程，会计算 RMSE 评估结果。
4. 认识共线性的危害，会用条件数做诊断，并能用自己的话解释"恒速时推力与阻力不可分"。

## 为什么学这一章

第 4 章我们学会了用仿真器生成船舶运动数据，第 6 章学会了用 pandas 整理试航数据并做训练/测试划分。接下来的问题是：拿到数据之后，怎么把模型里未知的系数"算"出来？这就是**参数辨识**——从实测数据反推模型中未知参数数值的过程。本项目的研究方案里，基线模型之一就是"最小二乘 + 逆动力学回归"的传统辨识路线，因此最小二乘是全书的枢纽工具：本章的阻尼系数辨识是它，第 9 章神经网络训练本质上也是"让误差最小"，只是参数从几个变成了几万个。同时，研究文档的可辨识性分析反复强调：不是"数据越多参数就越准"，如果激励设计不好，会出现**共线性**——几个参数纠缠在一起无法分开，最典型的就是"恒速航行时推力与阻力不可分"。本章我们会用几十行代码把这件事亲手演示出来。

## 7.1 把参数辨识写成 y = Φθ

先看一个人人都懂的例子：给一堆散点 `(x_i, y_i)` 配一条直线 `y = kx + b`。把每个数据点代入直线方程：

```text
y_1 = k * x_1 + b
y_2 = k * x_2 + b
...
y_N = k * x_N + b
```

这 N 个方程可以整齐地叠成一个矩阵方程 `y = Φθ`：

```text
[y_1]   [x_1  1]       
[y_2] = [x_2  1]  [k]
[...]   [...  ..]  [b]
[y_N]   [x_N  1]
```

逐项解释：

- `y`（因变量向量，N 行 1 列）：我们**观测到**的输出，比如测得的合力、测得的速度变化。
- `Φ`（大写 Phi，叫**设计矩阵**或回归矩阵，N 行 P 列）：每一列是一个**回归量**（regressor，即"用来解释 y 的已知量"），每一行对应一次观测。构造设计矩阵是参数辨识中唯一需要动脑筋的步骤。
- `θ`（希腊字母 theta，P 行 1 列）：**待求的参数**，比如这里的 `[k, b]`。

由于有测量噪声，通常 N ≫ P（方程比未知数多），没有精确解。**最小二乘**（least squares）的思想是：找一组 θ，让所有误差的平方和 `‖y - Φθ‖²` 最小。这个最优解不用自己推公式，NumPy 一行就能算。

```python
import numpy as np

rng = np.random.default_rng(0)
x = np.linspace(0, 10, 50)
k_true, b_true = 2.5, 1.0
y = k_true * x + b_true + rng.normal(0, 0.5, size=x.shape)  # 加噪声模拟实测

# 构造设计矩阵：每行是 [x_i, 1]，对应参数 [k, b]
Phi = np.column_stack([x, np.ones_like(x)])
theta, residuals, rank, sv = np.linalg.lstsq(Phi, y, rcond=None)
print("估计参数 [k, b] =", np.round(theta, 4))
print("真值       [k, b] =", [k_true, b_true])
print("设计矩阵的秩 =", rank)
print("奇异值 =", np.round(sv, 3))
```

运行结果（数值因噪声而略有偏差，属正常现象）：

```text
估计参数 [k, b] = [2.558  0.7744]
真值       [k, b] = [2.5, 1.0]
设计矩阵的秩 = 2
奇异值 = [41.486  3.549]
```

`np.linalg.lstsq(Phi, y, rcond=None)` 返回四个值，要养成全部接住的习惯：

- `theta`：最优参数估计；
- `residuals`：残差平方和（仅当列满秩时非空）；
- `rank`：设计矩阵的**有效秩**——有几列是真正"独立"的。这里 rank=2 等于列数，健康；如果小于列数，说明有列是多余的（7.4 节会看到这有多危险）；
- `sv`：**奇异值**，可以理解为每列提供信息量的"音量"，最小的奇异值接近 0 是危险信号。

`rcond=None` 只是关闭一个旧版警告，全书固定这样写即可。

## 7.2 RMSE：拟合好不好的统一尺子

参数辨识之后第一件事是问：拟合得怎么样？最通用的指标是 **RMSE**（均方根误差，root mean square error）：

```text
RMSE = sqrt( mean( (y_true - y_pred)^2 ) )
```

它的单位与 y 本身相同，可以直接理解为"预测值与真值偏差的典型大小"。本项目研究文档（第 4 章 §4.2.2）把分时窗开环 RMSE 定为模型验收的主度量，后文会用到它的简化版。

```python
def rmse(y_true, y_pred):
    """均方根误差：预测值与真值偏差的典型大小"""
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    return np.sqrt(np.mean((y_true - y_pred) ** 2))


y_fit = Phi @ theta                      # 拟合直线给出的 y
print("拟合 RMSE =", round(rmse(y, y_fit), 4))
```

输出 `拟合 RMSE = 0.4223`，和我们人为加入的噪声标准差 0.5 很接近——这是健康拟合的标志：**拟合残差大约等于噪声水平**。记住这个基准，7.4 节会用它揭穿一个陷阱。

## 7.3 完整实战：从仿真数据辨识线性阻尼系数

现在把前两节的工具用到本项目上。任务设定：我们有一艘"船"（简化仿真器），做了变转速机动试航，记录了转速和船速，要反推出模型里的未知系数。

先解释三个首次出现的领域术语：**纵荡速度 u** 是船沿前后方向的速度；**艏摇角速度 r** 是船头左右转动的快慢；**线性阻尼**是阻碍运动的力中与速度成正比的部分（速度越快阻力越大，系数 Xu、Nr 通常为负）。推进器**推力**是推船前进的力，转速 n 是它每秒转的圈数；本章采用"推力与转速平方成正比"的模型，这是教学简化（真实推力还与进速等因素有关，见研究文档第 2 章）。

### 7.3.1 简化 3DOF 仿真器

下面是本章的自给自足仿真器（把 7.2 节的 `rmse` 函数和 7.3 节所有代码块按顺序放进同一个 `.py` 文件即可运行）。它在第 4 章的基础上做了大幅教学简化：忽略附加质量与科氏力、三个运动通道解耦、只保留线性阻尼；参数数值也是随便取的教学值，不代表真实船舶量级。

```python
import numpy as np


def simulate(n1_seq, n2_seq, dt,
             m=500.0, Iz=200.0, d=1.0,
             kt=0.8, Xu=-20.0, Yv=-50.0, Nr=-30.0):
    """简化 3DOF 仿真器（教学简化版）。

    状态：eta = [x, y, psi]，nu = [u, v, r]
    输入：两台推进器转速 n1, n2（方位角固定为 0，即都朝正前方）
    返回：每一行 [x, y, psi, u, v, r]，共 len(n1_seq)+1 行
    """
    n_steps = len(n1_seq)
    eta = np.zeros(3)
    nu = np.zeros(3)
    log = np.zeros((n_steps + 1, 6))
    log[0] = np.concatenate([eta, nu])
    for k in range(n_steps):
        u, v, r = nu
        psi = eta[2]
        # 推进器合力/力矩（教学简化：推力与转速平方成正比，kt 为推力系数）
        X = kt * (n1_seq[k] ** 2 + n2_seq[k] ** 2)
        Y = 0.0
        N = d * kt * (n1_seq[k] ** 2 - n2_seq[k] ** 2)  # 左右转速差产生艏摇力矩
        # 动力学（教学简化：三通道解耦，只留线性阻尼）
        du = (Xu * u + X) / m
        dv = (Yv * v + Y) / m
        dr = (Nr * r + N) / Iz
        nu = nu + dt * np.array([du, dv, dr])
        # 运动学：欧拉积分更新位置姿态
        c, s = np.cos(psi), np.sin(psi)
        eta = eta + dt * np.array([c * u - s * v, s * u + c * v, r])
        log[k + 1] = np.concatenate([eta, nu])
    return log
```

### 7.3.2 生成"试航数据"

辨识想要成功，输入必须"动起来"——转速要有变化（这叫**激励**，即让系统产生响应的输入变化）。我们让两台推进器每 10 秒随机换一次转速，并给速度测量加少量噪声：

```python
# （接上文，同一文件）
dt = 0.1
t = np.arange(0, 300, dt)
rng = np.random.default_rng(42)
seg = int(10 / dt)  # 每 10 s 换一档
n1 = np.repeat(rng.uniform(5, 20, size=len(t) // seg + 1), seg)[:len(t)]
n2 = np.repeat(rng.uniform(5, 20, size=len(t) // seg + 1), seg)[:len(t)]

log = simulate(n1, n2, dt)                                     # "试航"
u_meas = log[:, 3] + rng.normal(0, 0.01, size=len(log))        # 测得的 u，含噪声
r_meas = log[:, 5] + rng.normal(0, 0.005, size=len(log))       # 测得的 r，含噪声
```

### 7.3.3 构造回归矩阵并辨识

关键是把动力学方程整理成 `y = Φθ` 的形式。纵荡通道的运动方程是 `m·du/dt = kt·(n1²+n2²) + Xu·u`，把已知量归置好：

- `y` = `m·du/dt`（质量视为已知的固定量，这是教学简化；du/dt 用相邻测点差分近似）；
- 第 1 列回归量 = `n1² + n2²`，对应参数 `kt`；
- 第 2 列回归量 = `u`，对应参数 `Xu`。

艏摇通道同理：`Iz·dr/dt = kt·d·(n1²−n2²) + Nr·r`。

```python
# （接上文，同一文件）
m, Iz, d = 500.0, 200.0, 1.0  # 质量/惯量/横向间距，视为已知固定量
du = (u_meas[1:] - u_meas[:-1]) / dt
dr = (r_meas[1:] - r_meas[:-1]) / dt

# 纵荡通道：m*du/dt = kt*(n1^2+n2^2) + Xu*u
y_s = m * du
Phi_s = np.column_stack([n1 ** 2 + n2 ** 2, u_meas[:-1]])
theta_s, _, rank_s, _ = np.linalg.lstsq(Phi_s, y_s, rcond=None)

# 艏摇通道：Iz*dr/dt = kt*d*(n1^2-n2^2) + Nr*r
y_r = Iz * dr
Phi_r = np.column_stack([d * (n1 ** 2 - n2 ** 2), r_meas[:-1]])
theta_r, _, rank_r, _ = np.linalg.lstsq(Phi_r, y_r, rcond=None)

kt_hat, Xu_hat = theta_s
Nr_hat = theta_r[1]
print(f"kt: 真值 0.8   辨识 {kt_hat:.4f}")
print(f"Xu: 真值 -20   辨识 {Xu_hat:.4f}")
print(f"Nr: 真值 -30   辨识 {Nr_hat:.4f}")
print("纵荡设计矩阵秩 =", rank_s, " 艏摇设计矩阵秩 =", rank_r)
print("纵荡力拟合 RMSE =", round(rmse(y_s, Phi_s @ theta_s), 4), "N")
```

运行结果：

```text
kt: 真值 0.8   辨识 0.8021
Xu: 真值 -20   辨识 -20.0549
Nr: 真值 -30   辨识 -30.0225
纵荡设计矩阵秩 = 2  艏摇设计矩阵秩 = 2
纵荡力拟合 RMSE = 69.9236 N
```

三个参数的辨识值与真值偏差都在 0.3% 以内，设计矩阵满秩。力拟合 RMSE ≈ 70 N 看起来不小，但对比一下噪声水平：差分会放大噪声，`m·du/dt` 的噪声量级约为 `500 × 0.01 × √2 / 0.1 ≈ 70 N`——残差恰好等于噪声，再次说明拟合是健康的。

### 7.3.4 留出段验证：分时窗开环 RMSE

按照第 6 章的数据划分思想，不能只用辨识过的那段数据自卖自夸。换一段**全新的激励**（新的随机种子），让真参数模型和辨识参数模型从相同初始条件各自开环滚动（free-running，中途不用真值校正），在 10 s / 30 s / 100 s 三个时窗上算 RMSE。这是研究文档 §4.2.2 验收度量的教学简化版——真项目里还要算位置 (x, y) 和艏向 ψ（艏向误差要取最短圆周差），本章只看 u 和 r。

```python
# （接上文，同一文件）
rng2 = np.random.default_rng(7)          # 换种子 = 换一段新机动
n1b = np.repeat(rng2.uniform(5, 20, size=len(t) // seg + 1), seg)[:len(t)]
n2b = np.repeat(rng2.uniform(5, 20, size=len(t) // seg + 1), seg)[:len(t)]
log_true = simulate(n1b, n2b, dt)                            # 真参数模型
log_id = simulate(n1b, n2b, dt, kt=kt_hat, Xu=Xu_hat, Nr=Nr_hat)  # 辨识模型

for win in (10, 30, 100):
    k = int(win / dt)
    e_u = rmse(log_true[1:k + 1, 3], log_id[1:k + 1, 3])
    e_r = rmse(log_true[1:k + 1, 5], log_id[1:k + 1, 5])
    print(f"{win:>4} s 窗: u 的 RMSE = {e_u:.5f} m/s, r 的 RMSE = {e_r:.5f} rad/s")
```

运行结果：

```text
  10 s 窗: u 的 RMSE = 0.00503 m/s, r 的 RMSE = 0.00423 rad/s
  30 s 窗: u 的 RMSE = 0.00995 m/s, r 的 RMSE = 0.01025 rad/s
 100 s 窗: u 的 RMSE = 0.00761 m/s, r 的 RMSE = 0.00718 rad/s
```

各时窗的滚动误差都在厘米/秒量级，辨识模型可用于后续仿真。最后用一张图直观看一下（绘图设置见第 5 章）：

## 7.4 共线性：当两个回归量"长得一样"

现在揭晓本章最重要的陷阱。前面一切顺利的前提是：设计矩阵的各列**各不相同**，提供不同的信息。如果两列几乎一模一样（这叫**共线性**，collinearity），数学上会怎样？

### 演示 A：两列几乎相同的回归量

```python
import numpy as np

rng = np.random.default_rng(1)
x1 = rng.uniform(0, 10, 200)
x2 = x1 * (1 + 1e-4 * rng.normal(size=200))   # x2 与 x1 几乎成比例
Phi = np.column_stack([x1, x2])
y_clean = 1.0 * x1 + 2.0 * x2                 # 真参数 [1, 2]

print("cond(Phi^T Phi) =", f"{np.linalg.cond(Phi.T @ Phi):.3e}")
for seed in (1, 2, 3):
    rng_n = np.random.default_rng(seed)
    y = y_clean + rng_n.normal(0, 0.01, size=200)   # 很小的测量噪声
    theta, _, rank, sv = np.linalg.lstsq(Phi, y, rcond=None)
    print(f"种子 {seed}: theta = [{theta[0]:8.2f}, {theta[1]:8.2f}], "
          f"拟合 RMSE = {rmse(y, Phi @ theta):.4f}, 秩 = {rank}")
```

（`rmse` 沿用 7.2 节的定义。）运行结果：

```text
cond(Phi^T Phi) = 4.673e+08
种子 1: theta = [    0.71,     2.29], 拟合 RMSE = 0.0092, 秩 = 2
种子 2: theta = [   -1.23,     4.23], 拟合 RMSE = 0.0095, 秩 = 2
种子 3: theta = [   -0.60,     3.60], 拟合 RMSE = 0.0103, 秩 = 2
```

请盯紧这组数字，它包含三个教训：

1. **参数估计变得任意**：真值是 `[1, 2]`，三次估计却天差地别，仅仅因为噪声种子不同——噪声被放大了几百倍。
2. **拟合 RMSE 依然很小**（≈0.01，恰是噪声水平）：拟合好 ≠ 参数对。"训练误差小"不能作为参数可信的证据。
3. 三次估计的**和都约等于 3**：数据其实只确定了 `θ₁+θ₂=3` 这一个组合，至于怎么拆，完全由噪声说了算。

`cond(Phi.T @ Phi)` 是**法方程** `ΦᵀΦθ = Φᵀy` 的**条件数**——衡量方程组的解对数据扰动有多敏感的指标，越大越病态（7.3 节健康案例只有约 4.5×10³，这里是 4.7×10⁸）。注意秩仍然显示 2：`lstsq` 不会替你报警，诊断要自己做。

### 演示 B：恒转速段上的推力与阻力

这件事在船上有直接的物理对应。把 7.3 的脚本接着写：改用恒转速 `n1 = n2 = 12` 试航，并只取船已匀速的稳态段来辨识 `[kt, Xu]`：

```python
# （接 7.3 的脚本，同一文件）
n1c = np.full_like(t, 12.0)
n2c = np.full_like(t, 12.0)
log_c = simulate(n1c, n2c, dt)
u_c = log_c[:, 3] + np.random.default_rng(0).normal(0, 0.01, size=len(log_c))

k0 = int(200 / dt)                       # 跳过前 200 s，只留匀速段
du_c = (u_c[k0 + 1:] - u_c[k0:-1]) / dt
Phi_c = np.column_stack([n1c[k0:] ** 2 + n2c[k0:] ** 2, u_c[k0:-1]])
theta_c, *_ = np.linalg.lstsq(Phi_c, m * du_c, rcond=None)
print("稳态段辨识 [kt, Xu] =", np.round(theta_c, 3), "（真值 [0.8, -20]）")
print("cond(Phi^T Phi) =", f"{np.linalg.cond(Phi_c.T @ Phi_c):.3e}")
print("力拟合 RMSE =", round(rmse(m * du_c, Phi_c @ theta_c), 4), "N")
```

运行结果：

```text
稳态段辨识 [kt, Xu] = [  198.118 -4953.553] （真值 [0.8, -20]）
cond(Phi^T Phi) = 8.582e+08
力拟合 RMSE = 49.232 N
```

估计值 `[198, -4954]` 与真值 `[0.8, -20]` 差了 250 倍，拟合 RMSE 却照样不大。原因一目了然：稳态时 `n1²+n2²=288` 是常数，`u≈11.52` 也是常数，两列回归量都几乎是常数向量，自然"长得一样"。再仔细算：`198.118 / 4953.553 ≈ 0.04 = 0.8 / 20`——**数据只锁定了 kt 与 Xu 的比值**（稳态只提供一个方程 `kt·288 + Xu·11.52 ≈ 0`），拆分是任意的。

这就是研究文档（第 2 章 §2.1）说的"恒速时推力与阻力不可分"的物理直觉：匀速航行时推力与阻力大小相等、方向相反，运动数据只能告诉你它们的**差**，分不出各自多大。文档还给出更一般的结论：即使变转速，只要推力、阻力允许是任意函数，给两者同时加上同一个 `g(u)` 净力不变，数据永远无法区分；本节只是这个结论在"两个常数系数"下的教学简化演示。§2.5 给出的工程对策顺序是：先删去重复的自由度并固定已知的力尺度 → 设计能区分候选结构的机动（就像 7.3 的变转速激励）→ 在开发集上选择正则化 → 冻结后评估；并且提醒：正则化只能挑出一个稳定解，**不能让本来不可辨识的物理分量变成由数据唯一确定**。

## 7.5 非线性问题怎么办：提一句

`y = Φθ` 要求方程对参数是**线性**的（参数只以乘系数的方式出现）。如果模型里参数藏在非线性关系中——比如阻尼写成 `Xu·u + Xu2·u·|u|` 之外更复杂的形式、或参数出现在指数/分母里——设计矩阵就构造不出来了。这时可以用 `scipy.optimize.least_squares`：给它一个"算残差"的函数和初始猜测，它帮你迭代找到残差平方和最小的参数。只演示最小用法，不展开：

```python
import numpy as np
from scipy.optimize import least_squares

# 非线性模型：y = a * (1 - exp(-b * x))，b 在指数里，写不成 y = Φθ
rng = np.random.default_rng(0)
x = np.linspace(0, 10, 50)
y = 3.0 * (1 - np.exp(-0.5 * x)) + rng.normal(0, 0.05, size=x.shape)


def residual(theta):
    a, b = theta
    return y - a * (1 - np.exp(-b * x))


result = least_squares(residual, x0=[1.0, 1.0])   # 给一个初始猜测
print("估计 [a, b] =", np.round(result.x, 3), "（真值 [3.0, 0.5]）")
```

输出 `估计 [a, b] = [3.034 0.481] （真值 [3.0, 0.5]）`。非线性最小二乘还有多初值、局部最优等新坑，真项目的辨识流程还会叠加滤波与平滑预处理，这些都超出本章范围。

## 常见错误

**错误 1：设计矩阵忘加常数列。** 想拟合 `y = kx + b` 却只写 `Phi = x.reshape(-1, 1)`，相当于强制直线过原点，b 无处安放，k 也被带偏（用 7.1 的数据试：得到 `k_hat = 2.673`，偏离真值 2.5）。
正确写法：有几个"常数项"就加几列 1，`Phi = np.column_stack([x, np.ones_like(x)])`，得到 `[2.558, 0.7744]`。

**错误 2：y 的量纲没凑对。** 构造 `y = Φθ` 时方程两边必须严格一致。比如在 7.3.3 中若忘记乘质量，写成 `y_s = du`，辨识结果会变成 `[0.0016, -0.04]`——恰好整体差了 500 倍（就是 m）。
正确写法：先把方程原样写在纸上，把每个已知量明确归到 y 或某一列里，再翻译成代码；辨识完立刻与真值（或量级常识）对比。

**错误 3：不看秩和条件数就相信结果。** `lstsq` 在秩亏、病态时**不报错**，照样返回一个看似正常的解（见 7.4，秩甚至仍显示为 2）。
正确写法：固定检查两件套——`rank == Phi.shape[1]`（列满秩）且 `np.linalg.cond(Phi.T @ Phi)` 不大（量级远大于数据精度允许的范围时警惕），最好再换一段数据看参数稳不稳。

**错误 4：用同一段数据既辨识又评估。** 用辨识过的数据算 RMSE 永远偏乐观，等于自己给自己批卷子——7.4 演示 A 已经证明"拟合好"与"参数对"可以毫无关系。
正确写法：按第 6 章的思路划分数据，辨识用一段、评估用另一段（7.3.4 的做法），条件允许时换机动类型、换工况做留出验证。
