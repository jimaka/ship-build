# 第 8 章 用类构建仿真环境
本教程以双全回转推进船舶 3DOF 建模项目为背景。

## 8.1 本章学习目标

- 理解 Python 类（class）的基本语法：`__init__`、`self`、属性与方法，会写会改一个简单的类。
- 把第 4 章"函数+散参"的简化仿真器封装成一个 `ShipEnv` 环境类。
- 掌握 RL 环境的标准接口：`reset()` 与 `step(action)`，理解 `step` 返回的五元组 `(obs, reward, terminated, truncated, info)` 每一项的含义，特别是 `terminated` 与 `truncated` 为什么不能混用。
- 会实现动作限幅（`np.clip`）、动作速率限制与观测归一化，理解它们存在的理由。
- 会用随机策略跑若干回合（episode），统计回合长度与回报，初步建立"策略—环境"交互的直觉。

## 8.2 为什么学这一章

第 4 章我们写的仿真器是一堆散落的函数和全局参数：别人想用你的模型，得先读懂每个变量是什么意思。强化学习（RL）的做法是把仿真器封装成一个**环境对象**：外界只需调用两个方法——`reset()` 开始新回合、`step(action)` 推进一步——不必关心内部细节。这正是本项目研究文档第 4 章 §4.5 "RL 训练契约"要求的工程形态：环境向算法承诺固定的接口与明确的越界语义。接口一旦对齐工业界通行的 Gymnasium 约定，今后接入 PPO 等 RL 训练库时环境代码基本不用改。本章物理模型仍是第 4 章那套教学简化版（简化的推力律与线性阻尼），重点在"封装"与"接口"。

## 8.3 类的基础：把数据和操作捆在一起

类（class）可以理解成"图纸"：图纸本身不是船，按图纸造出来的每艘船叫**实例**（instance）。实例身上存的数据叫**属性**（attribute），实例会做的动作叫**方法**（method）。下面把船舶的位置、艏向和速度捆成一个类：

```python
import numpy as np

class ShipState:
    """保存船舶的位置、艏向和速度。"""

    def __init__(self, x, y, psi, u, v, r):
        # self.x = x 表示"把传进来的 x 存到这个对象自己身上"
        self.x = x        # 位置 (m)
        self.y = y        # 位置 (m)
        self.psi = psi    # 艏向角 (rad)：船头指向与 x 轴的夹角
        self.u = u        # 纵荡速度 (m/s)：沿船头方向的速度
        self.v = v        # 横荡速度 (m/s)：沿船侧方向的速度
        self.r = r        # 艏摇角速度 (rad/s)：船头转动有多快

    def speed(self):
        """合速度大小。方法就是普通函数，只是第一个参数必须是 self。"""
        return np.sqrt(self.u ** 2 + self.v ** 2)

ship = ShipState(0.0, 0.0, 0.0, u=3.0, v=0.5, r=0.0)   # 按图纸造一个实例
print("ship.x =", ship.x)
print("ship.speed() =", round(ship.speed(), 4))
ship.u = 4.0                  # 属性可以随时修改
print("修改后 ship.speed() =", round(ship.speed(), 4))
```

预期输出：

```text
ship.x = 0.0
ship.speed() = 3.0414
修改后 ship.speed() = 4.0311
```

三个关键点：`__init__` 是**构造方法**，写 `ShipState(...)` 造实例时自动执行，负责把初始数据挂到对象身上；`self` 指"这个对象自己"，定义方法时必须写在第一个参数位置，调用时却不用传——`ship.speed()` 等价于 `ShipState.speed(ship)`，Python 自动把 `ship` 塞进 `self`；读写属性都用点号。方法除了算数返回，也常用来**修改对象自己的状态**，下面的环境类会反复用到。

## 8.4 把仿真器封装成环境类

### 8.4.1 回合、horizon 与 step 的五元组

RL 的训练单位是**回合**（episode）：从 `reset()` 开始、到结束为止的一段完整交互。回合不能无限长，环境会设一个最大步数，叫 **horizon**（时域）。比如 `dt=0.1 s`、`max_steps=300`，horizon 对应的物理时长就是 30 s。每调用一次 `step(action)`，环境返回**五元组**：

| 返回值 | 含义 |
|---|---|
| `obs` | 观测（observation）：策略能"看到"的信息，通常是归一化后的数组 |
| `reward` | 奖励：这一步的得分，RL 算法的目标是让它累计最大 |
| `terminated` | **任务意义上的结束**：成功到达终点，或失败（撞界、越出模型有效域） |
| `truncated` | **外部强制中断**：最常见是触顶 horizon 的时间上限 |
| `info` | 字典，放调试与统计信息（是否被限幅、结束原因等），策略不许用它做决策 |

`terminated` 和 `truncated` **不能混用**，区别在于"结束后还有没有未来"：任务失败而终（terminated）意味着这艘船的故事到此为止；时间到被掐断（truncated）只是"我们不继续仿真了"，船本身好端端的，物理上还有未来。RL 算法在回合收尾时要估算"以后还能拿多少奖励"，两种情况处理完全不同，混用会污染训练信号。研究文档 §4.5.4 因此废止了旧式"只用一个 done"的约定，要求两个标志分开上报，并在 `info` 里写清结束原因。本章教学简化：把"开出试验水域边界"定义为任务失败（terminated），"步数用满"定义为时间截断（truncated），二者不同时为真。

### 8.4.2 完整版 ShipEnv

下面把动力学封装进环境类，得到本章主代码。相对第 4 章的函数版新增：

1. **动作从外部传入**，语义是归一化四维目标 `[alpha1, n1, alpha2, n2]`（alpha 为方位角、n 为转速），每个分量 ∈ [−1, 1]，再映射到执行器单位——这是研究文档 §6.3.2 的起步动作接口（教学简化：允许转速反转，实船是否可反转取决于设备）。
2. **两级限幅**（§4.5.1）：先做硬限幅 `np.clip`——`np.clip(12.0, -10.0, 10.0)` 得 10.0，超出部分被裁掉——并在 `info["clipped"]` 留痕，不做"沉默的裁剪"；再做**速率限制**：真实推进器转向和加减速都要时间，指令阶跃后执行器只能以有限速度逼近目标。`step` 内动作链顺序固定为：原始动作 → 限幅 → 映射为目标 → 速率限制 → 实际响应。
3. **观测归一化**：各物理量除以自己的典型尺度，让观测大致落在 [−1, 1]；艏向角用 `sin/cos` 一对值表示，避免 359° 与 1° 在数值上差 358 的尴尬（§6.3.2 的观测约定）。神经网络对输入尺度很敏感，这是第 9、10 章的伏笔。
4. **奖励、终止与截断**：任务是"跟踪目标速度 3 m/s 并保持艏向"，奖励为归一化误差的负平方和，再加一项动作变化惩罚以鼓励操作平滑；开出边界 terminated，步数用满 truncated。
5. `reset()` 清空**全部**内部状态：运动状态、执行器实际位置、上一动作、步数计数器（§4.5.6 的 reset 约定）。

把下面代码保存为 `ship_env.py`（以下划线开头的方法是"内部零件"，约定外部不直接调用），后面的示例和练习都要 import 它：

```python
import numpy as np

class ShipEnv:
    """教学简化的双推进器船舶 3DOF 仿真环境（Gymnasium 风格接口）。"""

    def __init__(self, dt=0.1, max_steps=300):
        self.dt = dt                  # 时间步长 (s)
        self.max_steps = max_steps    # 每回合最大步数（horizon）
        self.m_u, self.m_v, self.m_r = 50.0, 80.0, 10.0     # 各自由度质量/惯量（教学简化取值）
        self.d_u, self.d_v, self.d_r = 20.0, 60.0, 25.0     # 线性阻尼系数
        self.C_T = 0.5                # 推力系数：T = C_T * n * |n|（沿用第 4 章）
        self.x_p = -0.5               # 推进器在重心后 0.5 m
        self.y1, self.y2 = 0.3, -0.3  # 1 号机在右舷、2 号机在左舷（同第 4 章）
        self.n_max, self.alpha_max = 10.0, np.pi   # 转速 (转/秒)、方位角 (rad) 限幅
        self.n_rate, self.alpha_rate = 3.0, 0.35   # 转速、方位角的变化率上限
        self.u_target = 3.0           # 任务：跟踪目标纵荡速度 (m/s) 并保持艏向
        self.bound = 50.0             # 试验水域边界 (m)，开出即任务失败
        self.u_scale, self.v_scale, self.r_scale = 6.0, 3.0, 2.0   # 观测归一化尺度
        self.state = None             # [x, y, psi, u, v, r]，以下均为内部状态，在 reset 中初始化
        self.n1 = self.n2 = self.alpha1 = self.alpha2 = 0.0   # 执行器实际状态
        self.prev_action = np.zeros(4)
        self.steps = 0

    def reset(self):
        """开始新回合：清空全部内部状态，返回 (obs, info)。"""
        self.state = np.zeros(6)
        self.n1 = self.n2 = self.alpha1 = self.alpha2 = 0.0
        self.prev_action = np.zeros(4)
        self.steps = 0
        return self._get_obs(), {}

    def step(self, action):
        """执行一步，返回五元组 (obs, reward, terminated, truncated, info)。"""
        action = np.asarray(action, dtype=float)
        # ① 硬限幅：动作裁剪到 [-1, 1]，并在 info 中记录（不做"沉默的裁剪"）
        clipped_action = np.clip(action, -1.0, 1.0)
        was_clipped = not np.allclose(action, clipped_action)
        # ② 归一化动作映射为执行器目标
        alpha1_t = clipped_action[0] * self.alpha_max
        n1_t = clipped_action[1] * self.n_max
        alpha2_t = clipped_action[2] * self.alpha_max
        n2_t = clipped_action[3] * self.n_max
        # ③ 速率限制：实际执行器只能逐步逼近目标
        self.alpha1 = self._rate_limit(alpha1_t, self.alpha1, self.alpha_rate)
        self.alpha2 = self._rate_limit(alpha2_t, self.alpha2, self.alpha_rate)
        self.n1 = self._rate_limit(n1_t, self.n1, self.n_rate)
        self.n2 = self._rate_limit(n2_t, self.n2, self.n_rate)
        # ④ 动力学积分（教学简化模型，欧拉法）
        self.state = self.state + self.dt * self._dynamics(self.state)
        self.steps += 1
        # ⑤ 计算奖励，判断终止与截断（terminated 优先，二者不同时为真）
        reward = self._calc_reward(clipped_action)
        x, y = self.state[0], self.state[1]
        terminated = abs(x) > self.bound or abs(y) > self.bound
        truncated = (self.steps >= self.max_steps) and not terminated
        obs = self._get_obs()
        info = {"clipped": was_clipped}
        if terminated:
            info["end_reason"] = "out_of_bound"
        elif truncated:
            info["end_reason"] = "time_limit"
        self.prev_action = clipped_action
        return obs, reward, terminated, truncated, info

    def _rate_limit(self, target, current, max_rate):
        """速率限制器：每步最多向目标靠近 max_rate * dt。"""
        delta = np.clip(target - current, -max_rate * self.dt, max_rate * self.dt)
        return current + delta

    def _dynamics(self, state):
        """状态导数：与第 4 章函数版相同的教学简化模型。"""
        x, y, psi, u, v, r = state
        X, Y, N = 0.0, 0.0, 0.0
        for n, alpha, y_p in [(self.n1, self.alpha1, self.y1),
                              (self.n2, self.alpha2, self.y2)]:
            T = self.C_T * n * abs(n)              # n 为负表示倒车，推力反向
            X += T * np.cos(alpha)
            Y += T * np.sin(alpha)
            N += self.x_p * T * np.sin(alpha) - y_p * T * np.cos(alpha)   # 对重心的力矩
        return np.array([
            u * np.cos(psi) - v * np.sin(psi),   # dx：船体系速度旋转到地面系
            u * np.sin(psi) + v * np.cos(psi),   # dy
            r,                                   # dpsi
            (X - self.d_u * u) / self.m_u,       # du
            (Y - self.d_v * v) / self.m_v,       # dv
            (N - self.d_r * r) / self.m_r,       # dr
        ])

    def _get_obs(self):
        """归一化观测：各分量大致落在 [-1, 1]，艏向角用 sin/cos 表示。"""
        x, y, psi, u, v, r = self.state
        return np.array([
            u / self.u_scale, v / self.v_scale, r / self.r_scale,
            np.sin(psi), np.cos(psi),
            self.n1 / self.n_max, self.n2 / self.n_max,
            self.alpha1 / self.alpha_max, self.alpha2 / self.alpha_max,
        ])

    def _calc_reward(self, action):
        """速度跟踪 + 保向 + 动作平滑的教学奖励（各项均已归一化）。"""
        x, y, psi, u, v, r = self.state
        e_u = (u - self.u_target) / self.u_scale          # 归一化速度误差
        e_psi = (psi + np.pi) % (2 * np.pi) - np.pi       # 艏向误差（目标 0）
        r_track = -(e_u ** 2) - 0.5 * (e_psi / np.pi) ** 2
        r_smooth = -0.05 * np.sum((action - self.prev_action) ** 2)
        return r_track + r_smooth
```

用一小段代码看看接口：

```python
env = ShipEnv()
obs, info = env.reset()
print("reset 返回的 obs:", np.round(obs, 3))
obs, reward, terminated, truncated, info = env.step([0.0, 1.0, 0.0, 1.0])
print("一步后 obs:", np.round(obs, 3))
print("reward=%.4f, terminated=%s, truncated=%s, info=%s" % (reward, terminated, truncated, info))
obs, reward, terminated, truncated, info = env.step([0.0, 2.5, 0.0, -1.3])
print("超限动作一步后 info =", info)
```

预期输出：

```text
reset 返回的 obs: [0. 0. 0. 0. 1. 0. 0. 0. 0.]
一步后 obs: [0.   0.   0.   0.   1.   0.03 0.03 0.   0.  ]
reward=-0.3500, terminated=False, truncated=False, info={'clipped': False}
超限动作一步后 info = {'clipped': True}
```

读一读输出：reset 后船静止、艏向为 0，所以 `cos(psi)=1`，obs 第 5 个分量是 1；给满转速指令一步后，转速因速率限制只爬到 0.3 转/秒（obs 里 0.03 = 0.3/10）；动作 `[0, 2.5, 0, -1.3]` 超出 [−1, 1]，被裁剪且 `info["clipped"]` 如实记录。

## 8.5 用随机策略跑回合

**策略**（policy）就是"看到观测后给出动作"的规则。最朴素的策略是完全不看观测、每步随机抽动作的**随机策略**——它是检验环境是否自洽的第一个试金石。下面跑 10 个回合，统计每回合的长度、回报（return，一回合奖励的累加）与结束原因：

```python
from ship_env import ShipEnv
import numpy as np

rng = np.random.default_rng(42)     # 固定种子，结果可复现
env = ShipEnv()
lengths, returns, reasons = [], [], []
for ep in range(10):
    obs, info = env.reset()
    total_reward = 0.0
    for t in range(env.max_steps):
        action = rng.uniform(-1.0, 1.0, size=4)   # 随机策略：每步随机抽动作
        obs, reward, terminated, truncated, info = env.step(action)
        total_reward += reward
        if terminated or truncated:
            break
    lengths.append(t + 1)
    returns.append(total_reward)
    reasons.append(info["end_reason"])
    print("回合 %2d: 长度 %3d 步, 回报 %8.2f, 结束原因 %s"
          % (ep, t + 1, total_reward, info["end_reason"]))
print("平均回合长度 %.1f 步, 平均回报 %.2f ± %.2f"
      % (np.mean(lengths), np.mean(returns), np.std(returns)))
print("越界终止 %d 次, 时间截断 %d 次"
      % (reasons.count("out_of_bound"), reasons.count("time_limit")))
```

预期输出：

```text
回合  0: 长度 300 步, 回报  -114.65, 结束原因 time_limit
回合  1: 长度 300 步, 回报  -117.01, 结束原因 time_limit
回合  2: 长度 300 步, 回报  -115.32, 结束原因 time_limit
……（回合 3–9 类似：长度均为 300 步，回报介于 −112.45 与 −117.86 之间）
平均回合长度 300.0 步, 平均回报 -115.24 ± 1.60
越界终止 0 次, 时间截断 10 次
```

10 个回合全部是 `time_limit`：随机动作零均值，双机推力互相抵消，船基本原地打转，永远开不出 50 m 边界，每回合都撑满 horizon。回报稳定在 −115 上下，这就是"什么都不学"的基准线。再看一个对照：始终满推正车的"鲁莽策略"。

```python
env = ShipEnv()
obs, info = env.reset()
total_reward = 0.0
for t in range(env.max_steps):
    obs, reward, terminated, truncated, info = env.step([0.0, 1.0, 0.0, 1.0])
    total_reward += reward
    if terminated or truncated:
        break
print("鲁莽策略: 长度 %d 步, 回报 %.2f, 结束原因 %s, 此时 x = %.1f m"
      % (t + 1, total_reward, info["end_reason"], env.state[0]))
```

预期输出：

```text
鲁莽策略: 长度 147 步, 回报 -13.66, 结束原因 out_of_bound, 此时 x = 50.2 m
```

它 147 步就冲出边界，回合因 `terminated` 提前结束。注意一个陷阱：它的回报（−13.66）比随机策略（−115.24）**高得多**，却是一次任务失败——它确实加速接近了目标速度，但随后冲过头还越了界。看 RL 训练曲线时，回报高不等于任务成功，失败率必须单独统计（这也是研究文档 §6.4 P2 的纪律）。

## 8.6 这就是 Gymnasium 接口约定

我们手写的接口不是自创方言，而是对齐了工业界通行的 **Gymnasium**（OpenAI Gym 的维护版）环境约定：

| 本章教学版 | Gymnasium / 项目契约中的对应 |
|---|---|
| `reset()` 返回 `(obs, info)` | 一致（还可传 `seed` 控制随机性） |
| `step(action)` 返回五元组 | 一致（旧版 Gym 的单个 `done` 已废止，见 §4.5.4） |
| `info["clipped"]`、`info["end_reason"]` | 契约要求的限幅留痕与结束原因 |
| 动作 = 归一化四维执行器目标 | §6.3.2 船舶起步动作接口 |

好处是：第 10 章接入 RL 训练库时，环境本体不需要重写，最多加一层薄薄的"适配壳"（声明观测/动作空间形状、随机种子等元数据）。本章环境与正式契约还有差距：单一 `dt`（正式环境区分积分步长、策略周期、伺服周期）、没有观测/动作空间对象、没有批量并行环境——这些留给后续章节和项目实施逐步补齐。

## 8.7 常见错误

**错误 1：方法定义漏写 `self`**

```python
class BadEnv:
    def reset():            # 漏了 self
        return np.zeros(9)
BadEnv().reset()
# TypeError: BadEnv.reset() takes 0 positional arguments but 1 was given
```

报错里的"1 was given"就是 Python 自动传入的实例自己。正确写法：`def reset(self):`。

**错误 2：`reset()` 忘了清空某个内部状态**

```python
def reset(self):
    self.state = np.zeros(6)
    # 忘了 self.steps = 0，也没清 self.prev_action 和执行器位置
```

后果很隐蔽：第二个回合开始时 `self.steps` 已等于 `max_steps`，第一步就 `truncated`，回合"秒结束"。研究文档 §4.5.6 专门列出 reset 必须清空的清单，写 `reset` 时应逐项对照。

**错误 3：把 `terminated` 和 `truncated` 混为一谈**

```python
terminated = self.steps >= self.max_steps      # 错：时间上限不是任务失败
truncated = abs(self.state[0]) > self.bound    # 错：越界失败不是时间截断
```

写反任何一个都会污染 RL 的训练信号（理由见 8.4.1）。口诀：**成败归 terminated，时间归 truncated**。

**错误 4：把可变对象写成类属性**

```python
class BadLog:
    history = []            # 类属性：所有实例共用同一张列表
a, b = BadLog(), BadLog()
a.history.append("step1")
print(b.history)            # ['step1'] —— b 什么都没做，却看到了 a 的数据
```

写在 `class` 体里的属性属于"图纸"，被所有实例共享；实例自己的数据必须写在 `__init__` 里：`self.history = []`。多个环境并行采样时，这个 bug 会让回合数据互相串扰，极难排查。

## 8.8 动手练习

**练习 1（改任务）**：把任务从"保持艏向 0"改成"跟踪目标艏向 30°"。需要改 `ShipEnv` 的哪两处？改完后验证：手动把 `psi` 设成 30°、`u` 设成目标速度时，奖励应为 0。

**练习 2（写一个会"看观测"的策略）**：随机策略不看观测，所以表现差。写一个最简单的比例策略：从 `obs` 还原 `u`，速度偏低就加大转速指令，`action = [0, n_cmd, 0, n_cmd]`，其中 `n_cmd = clip((u_target − u)/u_scale, −1, 1)`。跑 3 个回合，与随机策略的平均回报（−115.24）比较。

**练习 3（限幅统计）**：把随机策略改成从 [−2, 2] 均匀抽样（故意超范围），跑 5 个回合，统计 `info["clipped"]` 为 `True` 的步数占比，体会为什么契约要求限幅必须留痕。

## 8.9 本章小结与下一章预告

本章把第 4 章的散装仿真器封装成了 `ShipEnv` 类：类用 `__init__` 存参数、`reset()` 开回合、`step(action)` 返回五元组；动作经硬限幅与速率限制两级约束，观测做了归一化，回合区分任务终止（terminated）与时间截断（truncated）。这套 Gymnasium 风格接口是 RL 世界的通用插座——下一步要插进来的"用电器"，是一个能根据观测自己学出动作规则的神经网络策略。第 9 章《PyTorch 神经网络入门》将带你从零搭建第一个神经网络，为它在第 10 章充当策略做准备。

**练习 1**：改两处——`__init__` 增加目标艏向属性，`_calc_reward` 中艏向误差改为相对目标值。用继承演示（继承 = 新类沿用旧类的全部代码，只覆盖要改的部分）：

```python
from ship_env import ShipEnv
import numpy as np

class ShipEnvEx1(ShipEnv):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.psi_target = np.pi / 6          # 新增：目标艏向 30°

    def _calc_reward(self, action):
        x, y, psi, u, v, r = self.state
        e_u = (u - self.u_target) / self.u_scale
        e_psi = (psi - self.psi_target + np.pi) % (2 * np.pi) - np.pi   # 改动处
        r_track = -(e_u ** 2) - 0.5 * (e_psi / np.pi) ** 2
        r_smooth = -0.05 * np.sum((action - self.prev_action) ** 2)
        return r_track + r_smooth

env = ShipEnvEx1()
env.reset()
env.state[3] = env.u_target      # 令 u 正好等于目标速度
env.state[2] = np.pi / 6         # 令 psi 正好等于目标艏向 30°
print("对准目标时 reward =", env._calc_reward(np.zeros(4)))
env.state[2] = np.pi / 6 + np.pi / 2   # 偏离 90°
print("偏离 90° 时 reward =", round(env._calc_reward(np.zeros(4)), 4))
```

预期输出：

```text
对准目标时 reward = -0.0
偏离 90° 时 reward = -0.125
```

`(psi − psi_target + π) % (2π) − π` 把角度差折回 (−180°, 180°]，偏离 90° 时艏向项为 −0.5×(90/180)² = −0.125，与输出一致。

**练习 2**：

```python
from ship_env import ShipEnv
import numpy as np

env = ShipEnv()
for ep in range(3):
    obs, info = env.reset()
    total = 0.0
    for t in range(env.max_steps):
        u = obs[0] * env.u_scale            # 从归一化观测还原 u
        n_cmd = np.clip((env.u_target - u) / env.u_scale, -1.0, 1.0)
        action = np.array([0.0, n_cmd, 0.0, n_cmd])   # 双机同转，方位角保持 0
        obs, reward, terminated, truncated, info = env.step(action)
        total += reward
        if terminated or truncated:
            break
    print("回合 %d: 长度 %d 步, 回报 %.2f, 结束原因 %s, 最终 u = %.2f m/s"
          % (ep, t + 1, total, info["end_reason"], obs[0] * env.u_scale))
```

预期输出：

```text
回合 0: 长度 300 步, 回报 -45.72, 结束原因 time_limit, 最终 u = 0.72 m/s
回合 1: 长度 300 步, 回报 -45.72, 结束原因 time_limit, 最终 u = 0.72 m/s
回合 2: 长度 300 步, 回报 -45.72, 结束原因 time_limit, 最终 u = 0.72 m/s
```

回报 −45.72 远好于随机策略的 −115.24。三个回合一模一样：环境无噪声、策略是确定性的，同样的初始条件必然走出同样的轨迹。注意最终 u=0.72 m/s 并未到达 3 m/s——这是纯比例控制的稳态误差（误差一小转速指令就提前"松油门"），第 10 章学出来的策略可以精细得多。

**练习 3**：

```python
from ship_env import ShipEnv
import numpy as np

rng = np.random.default_rng(0)
env = ShipEnv()
n_clip, n_total = 0, 0
for ep in range(5):
    obs, info = env.reset()
    for t in range(env.max_steps):
        action = rng.uniform(-2.0, 2.0, size=4)   # 故意超范围的随机策略
        obs, reward, terminated, truncated, info = env.step(action)
        n_clip += int(info["clipped"])
        n_total += 1
        if terminated or truncated:
            break
print("clipped 步数占比: %d/%d = %.1f%%" % (n_clip, n_total, 100 * n_clip / n_total))
```

