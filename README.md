# 双全回转推进船舶 3DOF 灰箱建模调研

本仓库是一套面向双台全回转推进器、无舵、无首侧推船舶的建模调研文档。研究目标是在推进器敞水曲线未知、推进侧仅能连续量测两台推进器转速与方位角的条件下，建立可用于动力定位、低速靠泊等强化学习任务的 surge–sway–yaw 三自由度模型。

当前推荐路线是：**MMG-azimuth 解析骨架 + 神经网络学习船体水动力与有效推进幅值 + 定制湖试辨识 + 双基线开环/闭环验证 + OOD 有效域保护**。

> 文档给出的是技术路线与试验、验收协议，不代表模型已经完成实船验证。湖区水深、可用水域、传感器能力、装载状态和执行器限制等现场信息仍需在试验定稿前核实。

## 问题边界

### 已确定条件

- 船型：双台全回转推进器，无舵、无首侧推；
- 模型：水平面 3DOF，即纵荡 `u`、横荡 `v`、艏摇角速度 `r`；
- 已知输入：两台推进器的方位角 `α₁, α₂` 与转速 `n₁, n₂`；
- 未知信息：推进器敞水曲线及部分船体–推进器干扰参数；
- 主要数据源：平静、可重复的湖面实船试验；
- 主要用途：DP、低速靠泊等任务的强化学习训练环境；
- 评价原则：自由滚动和闭环表现优先，一步预测误差只作训练诊断。

### 当前不承诺的范围

- 未经对应数据验证的装载、水深、海况或运动包线；
- 高海况下完整的风、浪、流六自由度耦合；
- 未采集倒车数据时的完整四象限推进能力；
- 以 IMO 舵船限值直接判定全回转船合规；相关指标只作为统一参照；
- 模型越过 OOD 边界后继续自由外推。

## 核心技术结构

模型保留 3DOF 刚体与附加质量动力学，以及全回转推进器的解析力方向和力矩臂；网络只学习现有信息无法可靠给出的映射：

1. 船体水动力或其低维系数映射；
2. 每台推进器的有效推进幅值 `T(n, α, u, v, r, …)`；
3. 必要时，将推力减额、整流和船体–推进器干扰折算进可辨识的有效参数。

这种划分使 `sin/cos` 方向关系与力矩符号由解析结构保证，同时允许实船数据吸收未知推进特性。需要特别注意：模型学到的是当前船体、装载与来流条件下的**有效推进映射**，不是可脱离船体使用的推进器敞水曲线。

## 从调研到实施的准入门槛

| 阶段 | 开始前必须具备 | 主要输出 | 通过条件 |
|---|---|---|---|
| 试航定稿 | 湖区水深/尺度、吃水、传感器采样率与精度、机械限位已确认 | 冻结的 L1–L6 航次表和安全方案 | 计划航线满足现场安全条件，所有关键通道可统一时标采集 |
| 数据接收 | 原始量、校准记录、环境量、装载和航次元数据齐全 | 不可变原始数据包与数据字典 | 时间戳连续、单位明确、无无法解释的长缺口或饱和段 |
| 建模 | 训练/验证/测试划分已在训练前冻结 | 灰箱模型、两条基线和训练记录 | 可辨识性、共线性及残差诊断通过，不使用测试集调参 |
| 开环验收 | 三类模型使用相同数据、初值和执行器动态 | IMO 类指标及 10/30/100 s RMSE 报告 | 阈值由任务方预先冻结，最终测试集只用于冻结模型 |
| 闭环验收 | 控制律、增益、扰动回放和噪声模型冻结 | 保向/循迹、控制活动和长时稳定结果 | 第 4 章 C1–C4 全部通过 |
| RL 发布 | 有效域表、OOD 阈值、动作/速率限制和性能基准齐全 | 可版本化环境、模型卡和机器可读有效域 | 越界语义明确，域外不滚动，`step()` 吞吐满足训练预算 |

## 最小交付物

为使结果可复现，每次正式模型发布至少应包含：

- 原始数据清单、校准文件、数据字典和航次元数据；
- 数据清洗与状态重构配置，以及被剔除数据段和理由；
- 冻结的数据划分清单、随机种子和训练配置；
- 灰箱模型、传统 MMG 基线、传统辨识基线及可选黑箱消融；
- 开环、闭环、外推测试和吞吐基准报告；
- 模型卡：训练数据版本、适用域、已知限制和风险；
- 机器可读的有效域与 OOD 配置；
- 代码、依赖和模型权重的版本标识。

建议的数据包顶层结构如下；这是交付约定，不表示仓库中已存在这些目录：

```text
dataset_release/
├── raw/                 # 原始记录，只读留档
├── calibration/         # 传感器与执行器校准
├── metadata/            # 航次、装载、水深、风流信息
├── processed/           # 对齐、滤波和状态重构结果
├── splits/              # 冻结的 train/validation/test 清单
└── checksums.sha256      # 完整性校验
```

## 关键术语与符号

| 名称 | 含义 |
|---|---|
| MMG | 将船体、推进器和操纵装置的作用分解建模的操纵运动框架 |
| azimuth | 可绕竖轴回转并改变推力方向的推进装置 |
| 3DOF | 水平面纵荡、横荡、艏摇三自由度 |
| `u, v, r` | 船体坐标系纵向速度、横向速度、艏摇角速度 |
| `ψ` | 艏向角 |
| `nᵢ, αᵢ` | 第 `i` 台推进器的转速与方位角 |
| `X, Y, N` | 纵向力、横向力、艏摇力矩 |
| 有效推进映射 | 包含船体伴流、推力减额和尺度效应的推进输入到船体受力映射 |
| OOD | 超出训练数据分布或已验证运动包线的状态/动作 |
| 自由滚动 | 后续时刻使用模型预测状态继续积分，而非逐步喂入真值 |
| `h/T` | 水深与平均吃水之比；本报告以 `h/T ≥ 4` 作为深水试验目标 |
